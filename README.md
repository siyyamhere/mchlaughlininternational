# Mchlaughlin International — GitHub Pages Website

## Included
Five responsive pages, CSS/JS, rendered images from the supplied PDFs, and the original company profile/dental catalogue PDFs.

## Publish free with GitHub Pages
1. Create a GitHub account.
2. Create a new repository named `mchlaughlin-international`.
3. Upload every file and folder from this package.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
6. GitHub will give you a free `github.io` address.

## Contact form
GitHub Pages is static hosting. The current form uses a mailto fallback. For a true browser-submission form, create a free Formspree form and replace the `<form action=...>` in `contact.html` with the Formspree endpoint.

## Before launch
- Replace the temporary `MI` header mark with your official transparent logo (SVG/PNG) if available.
- Verify the phone/WhatsApp and email.
- Add approved product-level dental cards from the catalogue.
- Provide the verified surgical catalogue before publishing surgical product claims.
- Replace placeholder Privacy Policy / Terms text with your actual legal pages if needed.
